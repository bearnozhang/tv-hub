老板要求：向前人学习，不求突破只求稳定；核心诉求是「稳定、能用、不要一直更换链接」。

## 调研结论（社区经验）
TVBox 社区的核心共识：**「永久可用」是伪命题** —— 数据源生命周期通常只有 3-12 个月。
正确策略是「固定主通道 + 明确的备用清单 + 主通道能用就不换」。
社区原文印证了老板的话：「看到网上有人发某月最新稳定接口，就赶紧换掉手头还能用的，
结果新接口用两天又失效，回头找旧的已经找不到了。」

## 实测（本机，2026-10-05）
- Cloudflare Worker 主域：可用，1167 站，CT 正确，1.3s
- jsDelivr (fastly)：可用，1167 站，CT 正确，1.0s ← 最佳备用
- jsDelivr (cdn)：可用，1022 站（CDN 缓存滞后一版），CT 正确
- gh-proxy.com / gh.zrfme.com：内容最新但 CT=text/plain（校验 CT 的客户端会拒绝）
- GitHub raw 直连、jsDelivr gcore/testingcf/b-cdn：不可用

另测得：饭太硬备用域名 fty.888484.xyz/tv 返回的是 **JPEG 图片** ——
把 JSON 伪装成图片对抗封锁（其 .bmp 防屏蔽接口同理）。
我们**不采用**：它会牺牲 Content-Type 正确性，
而主通道是自建 Worker，无需靠伪装躲检测。
